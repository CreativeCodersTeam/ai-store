# dep-pr-cleanup — script tests

Unit tests for `skills/development/dep-pr-cleanup/scripts/`. `gh` is replaced by
`mock_gh/gh.py` (selected through `DEP_PR_CLEANUP_GH`), so the suite never touches the network
and needs no GitHub login. Python 3.8+ with the standard library only; runs the same on Windows.

```bash
S=skills/tests/development/dep-pr-cleanup/scripts
python3 $S/run_tests.py -v                              # all unit tests
python3 -m unittest discover -s $S/unit -t $S -p 'test_coverage.py'   # one test file
python3 $S/fixtures/build_fixtures.py                   # regenerate fixtures/scenario-mixed
```

Nothing to clean up: tests that need their own scenario write it to a temporary directory.

| File | Covers |
| --- | --- |
| `unit/test_versions.py` | target relations: equal, newer, newer-major, pre-release order, Maven qualifiers, PEP 440 specifiers, Docker variants and digests, SHA pins with version comments |
| `unit/test_manifests.py` | file classification and every supported line shape per ecosystem, Renovate annotations, lockfiles, unsupported and added files, CRLF |
| `unit/test_coverage.py` | the obsolete algorithm: subsets, ties, newer/major options, union, path identity, bot and base boundaries, unevaluable PRs, chains, non-transitive pair modes |
| `unit/test_scripts.py` | `collect_prs.py` (bot filter, extra bots, config file, flags, exit codes, truncation) and `analyze_prs.py` end to end on `scenario-mixed` with every option |
| `unit/test_verify_selection.py` | `verify_selection.py`: unchanged, new commits on a cover, closed cover, usage errors |

## Fixtures

`helpers.py` builds diffs (`npm`, `file_diff`, `hunk`, `lockfile`) and writes scenario
directories in the layout `mock_gh/gh.py` reads (`repo.json`, `prs.json`, `diffs/<n>.diff`,
`commits/<n>.json`). `fixtures/scenario-mixed/` is generated by `fixtures/build_fixtures.py`
and is also the scenario of the skill-behaviour evals in `../evals/`. Intended outcome with the
default options (newer counts, not across majors):
